{# The password rules, shown under a new-password field on /register and /forgot-password. The server is the authority: `strong_password` in flaskapp/forms.py decides. Without JavaScript this is a plain list of the rules. With it, static/js/password-rules.js ticks each one off as it is met and clears a stale server error once the password is acceptable. Keep these five items in step with `strong_password`. tests/e2e/test_password_rules.py checks the browser's verdict against `strong_password` for the same inputs, so a drift fails CI. #}
  • At least 12 characters
  • A lowercase letter (a–z)
  • An uppercase letter (A–Z)
  • A number
  • A special character, such as ! _ - or a space
